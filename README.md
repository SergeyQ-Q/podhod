# Подход — журнал тренировок

Личный трекер силовых тренировок: сайт, который работает в браузере телефона и сохраняет данные в облаке (Supabase), чтобы они были видны на всех устройствах.

Без облака сайт тоже работает, но тогда данные хранятся только в браузере.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `ai.js` | ИИ-тренер: чат, голос, действия в приложении |
| `config.js` | адрес и ключ вашего Supabase (заполнить один раз) |
| `supabase-setup.sql` | код, создающий таблицу в Supabase |
| `sw.js`, `manifest.webmanifest`, `*.png` | иконка на главном экране и работа без интернета |

## Шаг 1. Облако (Supabase), ~5 минут

1. Зарегистрируйтесь на https://supabase.com и нажмите **New project**. Придумайте имя (например `podhod`) и пароль базы, выберите ближайший регион. Подождите 1–2 минуты, пока проект создаётся.
2. Слева откройте **SQL Editor** → **New query**, вставьте всё содержимое файла `supabase-setup.sql` и нажмите **Run**. Должно появиться «Success».
3. Откройте **Project Settings → API** (может называться **Data API** / **API Keys**). Скопируйте:
   - **Project URL** (вида `https://xxxx.supabase.co`);
   - ключ **anon public** (или **publishable**).
4. Впишите их в `config.js`:
   ```js
   window.PODHOD_CONFIG = {
     url: "https://xxxx.supabase.co",
     anonKey: "eyJhbGciOi..."
   };
   ```
   Этот ключ публичный, так и задумано: без входа в аккаунт он ничего не даёт, а каждый пользователь видит только свои строки.
5. Чтобы не ждать письма, можно отключить подтверждение почты: **Authentication → Sign In / Providers → Email → Confirm email**: выключить.

## Шаг 2. Сайт на GitHub Pages, ~5 минут

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+** → **New repository**. Имя: `podhod`. Тип **Public**: для бесплатных Pages репозиторий должен быть публичным. Код сайта будет виден всем, а тренировки нет, они в Supabase. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **все файлы из этой папки** (уже с заполненным `config.js`). Нажмите **Commit changes**.
4. **Settings → Pages**. В **Source** выберите **Deploy from a branch**, ветка **main**, папка **/ (root)**, затем **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/podhod/`.

## Шаг 3. На телефоне

1. Откройте адрес сайта.
2. Добавьте его на главный экран:
   - **iPhone, Safari**: «Поделиться» → «На экран Домой»;
   - **Android, Chrome**: ⋮ → «Добавить на главный экран».
3. Откройте приложение с иконки, нажмите шестерёнку → **Создать аккаунт** (почта + пароль), затем **Войти**.
4. Если вы заходите не впервые, сразу нажимайте **Войти**. Тренировки подтянутся.

Точка на шестерёнке показывает синхронизацию: зелёная — всё в облаке, жёлтая — отправляется или нет сети (данные отправятся позже), красная — ошибка.

## Чтобы никто чужой не завёл аккаунт

После того как вы создали свой аккаунт: **Authentication → Sign In / Providers** → выключить **Allow new users to sign up**. Чужие данные в любом случае не видны, но так в вашей базе не появятся лишние пользователи.

## Ссылка для тренера

Тренер может составлять для вас планы тренировок: упражнения, подходы, вес, повторения, отдых и заметки.

1. Нужен вход в аккаунт (облако Supabase).
2. Шестерёнка → **Тренер** → **Создать ссылку для тренера** → **Копировать** или **Отправить**.
3. Тренер открывает ссылку в браузере, регистрация не нужна, и создаёт планы.
4. Планы появляются у вас на главном экране в разделе **От тренера**. Кнопка **Начать** запускает тренировку с весом и повторениями из плана, кнопка **В мои программы** сохраняет копию себе.

Тренер видит только свои планы, ваши тренировки и история ему недоступны. Ссылку можно отозвать в любой момент, но тогда планы от тренера удалятся.

Если вы выполнили `supabase-setup.sql` до появления этой функции, выполните его ещё раз: он дополнит базу и ничего не удалит.

## Переименование упражнений

Откройте упражнение (вкладка «Упражнения» или нажмите на название во время тренировки) → **Переименовать**. Работает и для стандартных упражнений. Прошлые тренировки и графики сохраняются.

## ИИ-тренер

Кнопка «ИИ» в нижнем меню или «🎤 Сказать ИИ-тренеру» во время тренировки. Можно писать или говорить:
«добавь присед 5 по 5», «жим 80 на 8», «создай упражнение жим в Смите», «составь программу на 3 дня», «разбери мой прогресс», «тренажёр занят — чем заменить?».

- На сайте нужен ключ Anthropic API: **Настройки → ИИ-тренер** (ключ с console.anthropic.com, хранится только на устройстве; оплата с вашего счёта Anthropic, обычно центы).
- В версии на claude.ai ключ не нужен: ИИ работает через аккаунт Claude.
- Голос работает в Chrome и Safari. Если не включается, используйте микрофон на клавиатуре телефона.

## Как обновить сайт

Загрузите изменённые файлы в репозиторий так же (**Add file → Upload files**) и увеличьте номер в `version.json`. Открытое приложение само перезагрузится на новую версию, когда вы к нему вернётесь.
